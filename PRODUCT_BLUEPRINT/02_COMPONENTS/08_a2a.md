# Agent-to-Agent (A2A)

## Arquitectura
El sistema A2A permite que el agente principal delegue tareas complejas a subagentes especializados.

### Componentes
- `AgentCard`: Define las capacidades de un subagente.
- `OrchestratorTool`: Tool que el LLM principal usa para invocar `delegate_task`.
- `A2AStrategy`: Interfaz para las estrategias de orquestación.
- `SupervisorStrategy`: LLM router que decide dinámicamente qué agente usar.
- `SequentialStrategy`: Pipeline que ejecuta agentes en orden predefinido.

### Modos de Contexto
- `isolated`: El subagente empieza con contexto limpio (ideal para revisores).
- `fork`: El subagente hereda el historial del padre (ideal para workers).

### Permisos
Los subagentes heredan el `PermissionGate` del padre y leen los permisos persistidos de `.harness/permissions.json` para evitar pedir confirmación dos veces.
